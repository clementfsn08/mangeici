# 🍽️ MANGEICI

> Ton resto, selon ton budget — Bénin 🇧🇯

**MANGEICI** est une plateforme de découverte de restaurants au Bénin. Elle connecte les visiteurs aux restaurants de leur quartier selon leur budget, zone et type de cuisine.

## 🌐 Site live
[mangeici.netlify.app](https://mangeici.netlify.app)

## 📁 Structure

| Fichier | Description |
|---|---|
| `mangeici-mvp.html` | Page d'accueil — recherche restaurants |
| `mangeici-inscription.html` | Inscription restaurant |
| `mangeici-login.html` | Connexion restaurateur |
| `mangeici-dashboard.html` | Dashboard restaurateur |
| `mangeici-admin.html` | Panneau administrateur |
| `mangeici-profil-resto.html` | Profil public restaurant (Premium) |
| `mangeici-vision.html` | Page "Notre vision" |
| `mangeici-laisser-avis.html` | Formulaire avis clients |
| `mangeici-compte.html` | Compte client & favoris |
| `mangeici-suggestions.html` | Suggestions utilisateurs |

## 🛠️ Stack technique

- **Frontend** : HTML5 / CSS3 / JavaScript vanilla
- **Base de données** : Supabase (PostgreSQL)
- **Paiement** : FedaPay
- **Hébergement** : Netlify
- **Polices** : Clash Display + Cabinet Grotesk
